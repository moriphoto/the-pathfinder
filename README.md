# The Pathfinder (Mr Pathfinder)

Walking companion for Cornwall and anywhere you plot a line.

**Live app (after Pages is on):**

https://moriphoto.github.io/the-pathfinder/

This repository is public so GitHub Pages works on a free GitHub account. HTTPS is required for phone GPS.

## Turn Pages on (one minute)

1. Open https://github.com/moriphoto/the-pathfinder/settings/pages
2. Under **Build and deployment → Source** choose **GitHub Actions** (if the workflow is present) **or** **Deploy from a branch**
3. If using a branch: Branch `main` / folder `/ (root)` → Save
4. Wait about a minute, then open the link above on your phone
5. Allow location → Share → Add to Home Screen

## Files

- `index.html` — page shell
- `pathfinder.css` — OS-style layout
- `pathfinder-a.js` — map, GPS, GPX, waypoints
- `pathfinder-b.js` — research, access land, field sheet
- `pathfinder-pois.json` — Penwith story places

Planning aid only. Not the definitive map of public rights of way.
